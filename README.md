### 学生成绩管理器（chap5 小结）

一个命令行成绩管理工具，实现了：

- 添加 / 查找 / 删除学生记录
- 计算平均分、最高分、最低分
- 按分数排序输出
- 根据分数自动评定等级（优秀 / 良好 / 及格 / 不及格）
- 统计不及格人数
- 把报告写入文件
