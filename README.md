### 重点练习说明

**学生成绩管理器（chap5 小结）**

一个命令行成绩管理工具，实现了：

- 添加 / 查找 / 删除学生记录
- 计算平均分、最高分、最低分
- 按分数排序输出
- 根据分数自动评定等级（优秀 / 良好 / 及格 / 不及格）
- 统计不及格人数
- 把报告写入文件

**模拟 12306 火车订票（chap5 实战三）**

使用字典嵌套列表存储车次信息（车次号为 key，车次详情为 value），实现了：

- 遍历输出所有车次信息
- 根据用户输入的车次号查询
- 使用 `dict.get()` 做安全取值，处理"车次不存在"的情况
- 输出购票结果
